# LogicHive シーケンス図

本ドキュメントでは、LogicHive の主要なユースケースにおけるコンポーネント間の相互作用を定義します。

## 1. アセット保存とバックグラウンド検証 (do_save_async)

ユーザーが新しい関数を保存し、自動的に検証（品質ゲート）が実行される際の流れです。

```mermaid
sequenceDiagram
    autonumber
    actor User as "ユーザー/AI"
    participant MCP as "MCP Server"
    participant ORC as "Orchestrator"
    participant DB as "SQLite Storage"
    participant EVM as "Evaluation Manager"
    participant EXE as "Execution Layer (Sandbox)"
    participant INT as "Logic Intelligence (LLM)"
    participant VEC as "Vector Store (ChromaDB)"

    User->>MCP: "save_function(name, code, test_code, ...)"
    MCP->>ORC: "do_save_async()"
    
    rect rgb(240, 240, 240)
        Note over ORC, EVM: "同期バリデーション"
        ORC->>ORC: "calculate_code_hash()"
        ORC->>DB: "get_function_by_hash()"
        ORC->>EVM: "get_evaluator('structural/static')"
        EVM-->>ORC: "Evaluator"
        ORC->>EVM: "evaluate()"
        Note right of ORC: "重大な構文エラーがあれば即時拒否"
    end

    ORC->>DB: "upsert_function(status='pending')"
    ORC-->>MCP: "Save accepted (Accepted)"
    MCP-->>User: "保存完了通知 (検証はバックグラウンドで継続)"

    rect rgb(220, 240, 255)
        Note over ORC, VEC: "非同期検証パイプライン (Background Task)"
        ORC->>EVM: "evaluate_all(code, test_code, ...)"
        
        par "並列評価"
            EVM->>EVM: "deterministic (AST解析)"
            EVM->>EXE: "runtime (サンドボックス実行)"
            EXE-->>EVM: "実行結果/テスト結果"
            EVM->>EVM: "security_static (脆弱性スキャン)"
            EVM->>INT: "ai_gate (AIによる論理レビュー)"
        end
        
        EVM-->>ORC: "最終評価レポート (Score, Reason)"
        
        ORC->>INT: "optimize_metadata (メタデータ補完)"
        ORC->>INT: "generate_embedding (ベクトル生成)"
        
        ORC->>DB: "update_verification_status(verified/failed)"
        
        opt "検証成功 (Status: verified)"
            ORC->>DB: "update_function_embedding()"
            ORC->>VEC: "upsert_vector()"
        end
    end
```

## 2. ハイブリッド検索 (do_search_async)

自然言語クエリから、セマンティック検索と再ランキングを用いて最適な関数を見つける流れです。

```mermaid
sequenceDiagram
    autonumber
    actor User as "ユーザー/AI"
    participant MCP as "MCP Server"
    participant ORC as "Orchestrator"
    participant INT as "Logic Intelligence (LLM)"
    participant DB as "SQLite Storage"

    User->>MCP: "search_functions(query)"
    MCP->>ORC: "do_search_async()"
    
    ORC->>INT: "expand_query(クエリ拡張)"
    INT-->>ORC: "expanded_query"
    
    ORC->>INT: "generate_embedding(query_emb)"
    INT-->>ORC: "vector"
    
    ORC->>DB: "find_similar_functions(vector)"
    Note right of DB: "SQLite + Vector Distance"
    DB-->>ORC: "initial_candidates (N*3件)"
    
    ORC->>INT: "rerank_results(query, candidates)"
    Note right of INT: "LLMによるコンテキスト適合度評価"
    INT-->>ORC: "reranked_results (上位N件)"
    
    alt "検索結果が弱いかつ生成意図がある場合"
        ORC->>INT: "generate_draft (AIによる下書き生成)"
        INT-->>ORC: "ai_draft"
    end
    
    ORC-->>MCP: "Final Search Results"
    MCP-->>User: "Markdown形式の検索結果"
```
