# LogicHive 改善計画: 一時仮想環境による依存関係解決

## 1. 問題の概要

### 発生している問題
`save_function()` 呼び出し時に、サードパーティパッケージ（stripe, scholarly, arxiv 等）を含む関数の保存が失敗する。

### 根本原因
`EphemeralPythonExecutor._acquire_pooled_env()` が、torch 以外の依存関係に対して `None` を返すため、LogicHive プロセス自身の `sys.executable` でコードが実行され、未インストールパッケージの `ImportError` が発生する。

### 問題の発生箇所
```
python.py:107-119 (_acquire_pooled_env)
  → torch 以外は None を返す
  → python.py:135-141 (_build_command)
  → pooled_env が None の場合、sys.executable を使用
  → harness.py で exec() 実行 → ImportError → StopIteration 例外
```

---

## 2. 解決策: 全依存関係に対して一時仮想環境を動的作成

### 基本方針
- **プールロジックを廃止**し、全ての依存関係に対して 0 から一時 venv を作成
- `uv` を使用して venv 作成 + パッケージインストール
- テスト実行後、即座に venv を削除
- PyTorch も他のパッケージと同様のフローで扱う（将来的にパフォーマンス問題になればプールを再導入）

### メリット
- シンプルで理解しやすい
- 全パッケージで同じ動作を保証
- プール管理の複雑さを排除

### デメリット
- PyTorch インストールに時間がかかる（初回: 30-120秒、キャッシュ後: 5-10秒）
- MVP 段階では正動が最優先のため、このデメリットは許容範囲

#### 新規追加するもの
```python
import asyncio
import os
import shutil
import subprocess
import uuid
from pathlib import Path
from typing import Optional

from core.logging_config import get_logger

logger = get_logger(__name__)

MIN_DISK_SPACE_GB = 3

class EphemeralEnv:
    """一時仮想環境を表すクラス"""
    def __init__(self, env_id: str, path: Path, python_executable: Path):
        self.env_id = env_id
        self.path = path
        self.python_executable = python_executable

async def create_ephemeral_env(
    dependencies: list[str],
    timeout: float = 60.0
) -> EphemeralEnv | None:
    """
    依存関係に基づいて一時仮想環境を動的に作成する。
    
    処理:
    1. ディスク容量チェック (最低3GB)
    2. uv venv で一時ディレクトリに venv 作成
    3. uv pip install で依存関係をインストール
    4. EphemeralEnv オブジェクトを返す
    
    Args:
        dependencies: インストールするパッケージ名のリスト
        timeout: インストールの最大待ち時間（秒）
    
    Returns:
        EphemeralEnv オブジェクト、または失敗時は None
    """
    # 1. ディスク容量チェック
    try:
        import shutil as shutil_module
        usage = shutil_module.disk_usage(str(Path.home()))
        free_gb = usage.free / (1024 ** 3)
        if free_gb < MIN_DISK_SPACE_GB:
            logger.warning(
                f"PoolManager: Cannot create ephemeral env - "
                f"only {free_gb:.1f}GB free (minimum: {MIN_DISK_SPACE_GB}GB)"
            )
            return None
    except Exception as e:
        logger.warning(f"PoolManager: Disk space check failed: {e}")

    # 2. 一時ディレクトリ作成
    env_id = str(uuid.uuid4())[:8]
    env_path = Path.home() / ".logichive" / "pools" / f"ephemeral_{env_id}"
    env_path.mkdir(parents=True, exist_ok=True)

    # 3. uv パスの解決
    uv_path = r"C:\Users\saiha\.local\bin\uv.exe"
    if not os.path.exists(uv_path):
        uv_path = "uv"  # fallback to PATH

    # 4. Python 実行パスの決定
    python_exe = (
        env_path / "Scripts" / "python.exe"
        if os.name == "nt"
        else env_path / "bin" / "python"
    )

    def run_cmd(cmd):
        return subprocess.run(
            cmd, capture_output=True, text=True, shell=True, encoding="utf-8"
        )

    try:
        # 5. venv 作成
        logger.info(f"PoolManager: Creating ephemeral env {env_id} for {dependencies}")
        vcmd = f'"{uv_path}" venv --system-site-packages "{env_path}"'
        res = await asyncio.to_thread(run_cmd, vcmd)
        
        if res.returncode != 0:
            logger.error(f"PoolManager: uv venv failed: {res.stderr}")
            shutil.rmtree(env_path, ignore_errors=True)
            return None

        # 6. 依存関係インストール
        if dependencies:
            pkg_str = " ".join(dependencies)
            python_exe_str = str(python_exe)
            
            # hardlink モードで試行
            icmd = (
                f'"{uv_path}" pip install --link-mode=hardlink '
                f'--python "{python_exe_str}" {pkg_str}'
            )
            res = await asyncio.to_thread(run_cmd, icmd)
            
            if res.returncode != 0:
                # hardlink 失敗 → copy モードにフォールバック
                logger.warning(
                    f"PoolManager: hardlink failed, falling back to copy: {res.stderr[:200]}"
                )
                icmd = (
                    f'"{uv_path}" pip install --link-mode=copy '
                    f'--python "{python_exe_str}" {pkg_str}'
                )
                res = await asyncio.to_thread(run_cmd, icmd)
            
            if res.returncode != 0:
                logger.error(f"PoolManager: uv pip install failed: {res.stderr}")
                shutil.rmtree(env_path, ignore_errors=True)
                return None

        # 7. 成功 - EphemeralEnv オブジェクトを返す
        new_env = EphemeralEnv(env_id, env_path, python_exe)
        logger.info(f"PoolManager: Ephemeral env {env_id} created successfully")
        return new_env

    except Exception as e:
        logger.error(f"PoolManager: Ephemeral env creation failed: {e}", exc_info=True)
        if env_path.exists():
            shutil.rmtree(env_path, ignore_errors=True)
        return None


async def destroy_ephemeral_env(env: EphemeralEnv):
    """
    一時仮想環境を破棄する。
    
    処理:
    1. shutil.rmtree で venv ディレクトリを削除
    2. 削除失敗時は rename → 後片付けに委譲
    """
    def cleanup():
        if not env.path.exists():
            return
        try:
            shutil.rmtree(env.path)
            logger.debug(f"PoolManager: Destroyed ephemeral env {env.env_id}")
        except OSError:
            # ファイルロック等で削除失敗 → rename で後片付け
            try:
                fallback = Path.home() / ".logichive" / "pools" / f"cleanup_{env.env_id}"
                env.path.rename(fallback)
                logger.debug(f"PoolManager: Renamed {env.path} to {fallback} for cleanup")
            except Exception:
                logger.warning(f"PoolManager: Failed to cleanup {env.path}")

    await asyncio.to_thread(cleanup)
```

### 4.2. `src/core/execution/python.py`

#### 変更箇所 1: `_acquire_pooled_env` メソッドの書き換え

```python
# 変更前
async def _acquire_pooled_env(self, dependencies):
    if not ENABLE_ENV_POOLING or not dependencies:
        return None

    from .pool import pool_manager

    target_spec = None
    if any("torch" in d.lower() for d in dependencies):
        target_spec = "torch-gpu" if pool_manager.has_gpu else "torch-cpu"

    if target_spec:
        return await pool_manager.acquire(target_spec, timeout=1.0)
    return None

# 変更後
async def _acquire_pooled_env(self, dependencies):
    """
    依存関係に基づいて一時仮想環境を取得する。
    全ての依存関係に対してオンデマンドで venv を作成する。
    """
    if not dependencies:
        return None

    from .pool import create_ephemeral_env
    return await create_ephemeral_env(dependencies)
```

@pytest.mark.asyncio
async def test_python_executor_with_third_party_dep():
    """
    サードパーティパッケージを含む関数が正しく実行できることを検証。
    一時仮想環境が自動作成されることを確認。
    """
    executor = EphemeralPythonExecutor()
    
    # json は標準ライブラリなので、サードパーティテストには不適切
    # 実際のサードパーティテストはスキップ扱いにする
    # （CI環境ではパッケージインストールに時間がかかるため）
    code = "import json\ndef check(): return json.dumps({'status': 'ok'})"
    test_code = "assert check() == '{\"status\": \"ok\"}'"
    
    result = await executor.execute(code, test_code)
    
    assert result.status == ExecutionStatus.SUCCESS
    assert "Tests Passed" in result.results[0].data


@pytest.mark.asyncio
async def test_ephemeral_env_cleanup():
    """
    一時仮想環境がテスト実行後に正しく破棄されることを検証。
    """
    from core.execution.pool import create_ephemeral_env, destroy_ephemeral_env
    
    # 一時環境を作成
    env = await create_ephemeral_env(["requests"])

    # 破棄

## 5. 実行フロー（修正後）

```
save_function(name="stripe_func", code="import stripe...", test_code="...")
  │
  ▼
orchestrator.py: do_save_async()
  ├─ extract_dependencies(code) → ["stripe"]
  ├─ sqlite_storage.upsert_function(data) → status="pending"
  └─ asyncio.create_task(_run_async_verification_pipeline())
      │
      ▼
      [バックグラウンド]
      RuntimeEvaluator.evaluate()
        │
        ▼
        EphemeralPythonExecutor.execute(dependencies=["stripe"])
          │
          ├─ _acquire_pooled_env(["stripe"])
          │   │
          │   └─ create_ephemeral_env(["stripe"])
          │       ├─ ディスク容量チェック
          │       ├─ uv venv --system-site-packages <tempdir>
          │       ├─ uv pip install stripe
          │       └─ EphemeralEnv を返す
          │
          ├─ _build_command(pooled_env, harness_file)
          │   └─ return [venv_python, harness_file]
          │
          ├─ _run_subprocess()
          │   └─ harness.py 実行:
          │       exec("import stripe...") → 成功
          │       exec("assert check()...") → 成功
          │       sys.exit(0)
          │
          └─ finally: destroy_ephemeral_env()
              └─ shutil.rmtree(venv_path)
```

## 7. ロールバック計画

問題が発生した場合、以下のステップでロールバックする:

1. `git revert` で変更を戻す
2. 既存のプールロジックが復活する
3. その場合、サードパーティパッケージの関数保存は引き続き失敗する

---

## 8. 今後の最適化（MVP 後）

MVP が安定したら、以下の最適化を検討する:

1. **プールの再導入**: PyTorch 等の重いパッケージに対して事前プールを再導入
2. **パッケージキャッシュ**: `uv` のキャッシュを活用して、2回目以降のインストールを高速化
3. **並列実行**: 複数の関数保存を並列処理する場合の venv 作成の最適化
